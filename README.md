# Проект для типографии

Это веб-приложение для типографии, которое упрощает процесс приема и обработки заказов на печать фотографий. Клиенты могут загружать свои фотографии, а система автоматически обрабатывает их и готовит к печати.

Ключевая цель проекта — минимизировать ручной труд, ускорить выполнение заказов и предоставить удобный инструмент как для клиентов, так и для сотрудников типографии. Платформа автоматически обрабатывает загруженные изображения, готовит их к печати и позволяет отслеживать статус каждого заказа в реальном времени.

## 🚀 Технологии

-   **Бэкенд:** Python, Django
-   **База данных:** PostgreSQL
-   **Кэш и брокер сообщений:** Redis
-   **Фоновые задачи:** Celery
-   **Интеграции:** Telegram Mini App
-   **Развертывание:** Docker, Gunicorn

## 🐳 Сервисы Docker

Проект состоит из следующих сервисов:

-   `frontend`: Отвечает за отображение пользовательского интерфейса для клиентов.
-   `web`: Основной сервис Django-приложения, работающий под управлением Gunicorn.
-   `worker`: Воркер Celery, выполняющий асинхронные задачи (например, обработка изображений).
-   `beat`: Планировщик периодических задач Celery.
-   `telegram_bot`: Сервис, обеспечивающий работу бэкенда для Telegram Mini App.
-   `redis`: Брокер сообщений для Celery и кэш.
-   `db`: База данных PostgreSQL для хранения информации о заказах и пользователях.
